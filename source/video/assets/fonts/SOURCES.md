# Font sources

Noto Sans SC: Google Fonts v41, variable weights 400–600, unicode-range subsets.
https://fonts.googleapis.com/css2?family=Noto+Sans+SC:wght@400..600&display=swap
https://github.com/google/fonts/tree/main/ofl/notosanssc

Inter: version 4.1, normal variable font.
https://rsms.me/inter/
https://github.com/rsms/inter/tree/v4.1

Noto Serif SC: Google Fonts v36, weight 600, five-character subset for the wordmark 私人放映室 only.
https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@600&text=私人放映室
https://github.com/google/fonts/tree/main/ofl/notoserifsc

All families retain their SIL Open Font License. CSS URLs are rewritten to sibling static files; runtime font loading uses the site origin.

ZCOOL XiaoWei: Google Fonts, weight 400, full CJK coverage (7,016 glyphs), converted to woff2.
https://fonts.googleapis.com/css2?family=ZCOOL+XiaoWei
https://github.com/googlefonts/zcool-xiaowei

Cormorant Garamond: Google Fonts, weights 600 and 700, Latin subset.
https://fonts.googleapis.com/css2?family=Cormorant+Garamond:wght@600;700

Outfit: Google Fonts, weights 400/500/600/700, Latin subset.
https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700

All three retain their SIL Open Font License; see ZCOOLXiaoWei.LICENSE,
CormorantGaramond.LICENSE and Outfit.LICENSE. CSS URLs are rewritten to sibling
static files; runtime font loading uses the site origin.
