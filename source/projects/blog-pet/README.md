# 柚柚 · 博客里的小精灵

独立演示入口：`/projects/blog-pet/`。博客通过 `_config.flatpaper.yml` 的 `inject.bottom` 加载 `widget.js`，首页、文章页和其他主题页面都会显示同一个组件。

- 拖动名字或人物移动；位置按可用屏幕范围的比例保存，刷新、翻页和窗口缩放后恢复。
- 名字获得焦点后，方向键移动 10 像素，Shift 加方向键移动 30 像素，Home 回到右下角。档案里也有复位按钮。
- 摸摸、喂点心、睡觉、亲密度、四套衣服及自动换装共享浏览器本地存档。收起状态也会保存。
- 闲置时自然眨眼，随鼠标轻轻歪头；遵循系统减少动态效果设置。
- 桌面默认只显示人物，靠近或键盘聚焦才展开操作。操作栏和气泡独立浮动，不改变人物位置；气泡在 4 至 7 秒后消失，每个标签页的浏览会话只问候一次。
- 手机默认是 56 像素小头像，点击展开，点击页面或闲置 10 秒后收回。触控按钮至少 44 像素高；键盘打开的操作和档案不会在使用中自动收回。
- 四套衣服各有 32 帧透明动作图集：站立眨眼、摸头、吃饼干、伸懒腰。摸头 1.9 秒、吃饼干 2.6 秒、伸懒腰 2.4 秒，各自安排起势、停顿和收势；吃饼干会重复轻咬。
- 动作首尾复用同一张站姿，按透明边界裁切、统一脚底位置，帧间柔化叠加轻微头发、衣摆形变和呼吸。换装和入睡、醒来有 360 毫秒柔和过渡；睡姿沿用原图集，没有新增坐下的逐帧动画。
- 一个播放器管理动作时钟。连续摸头不会重启动作；后台、收起和拖动时暂停，恢复后从原进度继续。减少动态效果时显示代表姿势，不启动持续绘制；图集缺失或损坏时回退到原来的 CSS 姿势。
- 已解码、裁切的衣服帧按需缓存，加载失败保留当前衣服。拖动不触发摸头，吃完饼干后才能继续喂食。小档案中可触发伸懒腰。
- 后台暂停循环动作、眨眼和自动换装；鼠标跟随与拖动按动画帧合并，避免每次指针事件都读取布局。
- Shadow DOM 隔离组件样式；跟随博客暗色模式。独立静态音乐站和壁纸站没有加载此组件。

`widget.html` 是组件内容，`widget.css` 是隔离样式，`app.js` 负责交互，`core.js` 提供存档和边界计算，`motion.js` 提供可测试的时钟与图集边界算法，`renderer.js` 负责 Canvas 播放。`assets/` 保存透明图集及配套素材，v1 原图保留。

动作演示：`/projects/blog-pet/motion-preview.html`。可同时重播四套衣服的动作，暂停查看表情，不改写桌宠存档。

验证：`node --test test/*.test.cjs`，`npm run build`。浏览器检查覆盖首页、文章页、翻页位置记忆、拖动不误触、键盘展开与复位、气泡自动消失、换装过渡、眨眼、收起后刷新、暗色模式及 390 像素窄屏头像与面板。窄屏检查不等同于真实手机验收。

动作升级验证：新增时钟、透明边界算法和模拟画布调度测试，涵盖动作完成只回调一次、连续点击不重启、暂停续播、减少动态效果、图集缺失回退。浏览器检查了四套服装的点心和伸懒腰、摸头归位、手动换装、睡醒、收起后绘制计数不变、拖动不误触，以及 390 像素展开后的 44 像素按钮。睡姿仍使用 v1 单帧和柔和过渡。
